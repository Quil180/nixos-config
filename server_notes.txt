    │  ⚠️ ARCHITECTURE NOTES — DO NOT FORGET:
    │  ┌─────────────────────────────────────────────────────────────────┐
    │  │ 1. Enable Memory Ballooning on every VM (Hardware → Memory →     │
    │  │    check "Ballooning Device"). Requires qemu-guest-agent inside  │
    │  │    each VM — NixOS: `services.qemuGuestAgent.enable = true;`     │
    │  │    Debian: `apt install qemu-guest-agent`.                       │
    │  │ 2. Enable KSM on the Proxmox HOST (host-wide, not per-VM):       │
    │  │      `echo 1 > /sys/kernel/mm/ksm/run`, persist via ksmtuned.    │
    │  │ 3. Auth model: WireGuard gates access, each service handles its  │
    │  │    own login/2FA natively. No forward-auth layer needed.        │
    │  │ 4. GPU passthrough: enable IOMMU in BIOS + GRUB                  │
    │  │    (`intel_iommu=on` or `amd_iommu=on`), bind GPU to vfio-pci    │
    │  │    if passing to a VM. Toast is an LXC, so instead bind-mount    │
    │  │    /dev/dri (and /dev/nvidia* if Nvidia) into the container and  │
    │  │    set cgroup device permissions (unprivileged LXC needs the    │
    │  │    idmap/device allow lines in the .conf) — no vfio needed.     │
    │  │ 5. PBS now lives on Breadbox, not Bakery — a Bakery boot-drive   │
    │  │    failure no longer takes out your restore path. Residual risk │
    │  │    is now Breadbox itself: it holds live data AND backups. See  │
    │  │    off-box copy note under Pasta below.                         │
    │  │ 6. Recheck Grafana RAM panels after ~1 week uptime for real trim │
    │  │    candidates — you now have a few GB more headroom from moving │
    │  │    Pasta off Bakery; Biscotti below already uses some of it.    │
